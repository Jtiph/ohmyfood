# OhMyFood 🍽️

Site responsive de réservation de restaurants gastronomiques permettant aux utilisateurs de consulter les menus et préparer leur commande avant leur arrivée.

## Features

- Intégration responsive mobile, tablette et desktop
- Pages de menus de restaurants
- Animations CSS interactives
- Navigation fluide entre les pages
- Architecture CSS organisée avec SASS
- Approche “mobile first”

## Tech Stack

- HTML5
- CSS3
- SASS
- Animations CSS
- Responsive Design
- Figma
